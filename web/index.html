Set your preferences and see which cocktails fit all of them at once. The chart, the bars and the table all react to the same filters.

The website reads web/data/cocktails.json, which is created by the Python download script. In a terminal, in the project folder, run:

python fetch_data.py
python serve.py

Then reload this page. (See the README for details.)
